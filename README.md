# Movie Ticket Booking Calculator

## 📌 Project Description
Movie Ticket Booking Calculator is a beginner-friendly Python project developed as part of my FreeCodeCamp Python learning journey.

This program checks ticket booking eligibility based on age and show time, calculates membership discounts and extra charges, applies seat-type service charges, and determines the final movie ticket price.

## 🎯 Features
- Checks age-based ticket booking eligibility.
- Checks eligibility for evening shows.
- Applies membership discounts based on conditions.
- Adds extra charges for evening shows or weekends.
- Calculates service charges based on seat type.
- Calculates the final ticket price.
- Uses conditional logic to determine booking eligibility.
